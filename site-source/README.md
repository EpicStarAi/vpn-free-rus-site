# Интернет без ограничений RUS

Корпоративный сайт московского технологического и digital-центра. Проект
объединяет удалённый отдел продаж, маркетинг, ведение социальных сетей,
AI-автоматизацию и будущую корпоративную инфраструктуру EPIC☠️VPN AI. Сайт
собран на vinext. Рабочая цепочка проекта: GitHub → n8n → Codex → VPS.
Replit исключён из production-процесса и больше не рассматривается как канал
публикации `freerus.site`.

## Возможности

- отдельные страницы продаж, маркетинга, социальных сетей и цифровизации;
- квиз по выбору услуги и калькулятор состава проекта без фиксации цены;
- корпоративные заявки и лист ожидания VPN с постоянным хранением в D1;
- блог, видео с Наташей Фри и база пошаговых инструкций;
- каталог AI-агентов и AI-инфлюенсеров, сбор виртуальной команды и демо ролей;
- DraftFly Approval Center с обязательным подтверждением внешних действий;
- отдельная страница пилотного запуска EPIC☠️VPN AI без заявления о доступности;
- структура кейсов без выдуманных клиентов, цен и показателей;
- обезличенная агрегированная аналитика с согласия читателя;
- Organization и Service JSON-LD, Open Graph, sitemap, robots, 404 и
  error-страницы;
- централизованное управление услугами, тарифами, кейсами, FAQ и статусом VPN
  через `data/corporate.ts`, публикациями и контактами через `data/site.ts`.

## Production-цепочка

Подробная схема размещения зафиксирована в `docs/DEPLOYMENT_CHAIN.md`.

- GitHub хранит исходники и историю изменений.
- n8n запускает редакционные и операционные автоматизации.
- Codex готовит изменения, проверяет сборку и формирует релизный коммит.
- VPS обслуживает публичный сайт, API, базу данных и фоновые процессы.

## Дальнейшее развитие

переделки публичных страниц.
