# FREE RUS — Sales & Trial Bot

## Что делает этот импорт

- отвечает пользователю на `/start`;
- показывает пилотное предложение: **3 дня бесплатно**, **149 ₽ первый месяц**, далее **249 ₽/месяц**, годовой вариант **1 490 ₽**;
- принимает текстовые команды: `ТЕСТ`, `ТАРИФЫ`, `РЕФЕРАЛ`, `ПОДДЕРЖКА`;
- использует credential **TELEGRAM_FREE_RUS_VPN_BOT**;
- не выдаёт доступ, не принимает платежи и не начисляет реферальные дни автоматически — это защита от ложных продаж до подключения реальных сервисов.

## Деплой в n8n

1. Скачайте файл `FREE-RUS-Sales-Trial-Bot.json`.
2. В n8n создайте новый workflow → меню **Import from File**.
3. Выберите скачанный файл.
4. В обоих Telegram-узлах выберите credential **TELEGRAM_FREE_RUS_VPN_BOT**.
5. Нажмите **Save**, затем **Publish/Activate**.
6. Откройте [@FREE_RUS_VPN_BOT](https://t.me/FREE_RUS_VPN_BOT), отправьте `/start`, затем `ТАРИФЫ`.

## Что подключить до старта реальных продаж

1. Платёжный провайдер с webhook об успешной оплате.
2. Сервис, который автоматически выдаёт и отзывает VPN-доступ.
3. Хранилище пользователей, дат окончания теста, платежей и рефералов.
4. Политику обработки персональных данных и условия сервиса.
5. Отдельные ветки n8n для: `trial_started`, `payment_succeeded`, `referral_reward`, `access_expired`.

Пока этих пяти блоков нет, workflow корректно работает как пилотный бот сбора заявок и консультаций, но не делает обещаний о выдаче доступа автоматически.
